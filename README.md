# SpendDNA – Intelligent Bank Transaction Analyzer

## 📌 Overview

SpendDNA is a Python-based financial analytics project that analyzes six months of bank transaction data.

## Features

- Transaction Parser
- Vendor Extraction
- Category Tagging
- Spending Overview
- Monthly Trend Analysis
- Time-of-Day Analysis
- Z-Score Anomaly Detection
- Spending Archetype Detection

## Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

## Dataset

- rahul_transactions.csv

## Output

- Spending Summary
- Vendor Analysis
- Category Analysis
- Monthly Analysis
- Anomaly Detection
- Spending Personality
- Final ASCII Report
